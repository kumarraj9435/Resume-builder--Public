🚀 DEPLOYMENT IN 5 MINUTES (GitHub Pages - FREE)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Create GitHub Account
   → Go to: https://github.com
   → Sign Up (Free)
   
STEP 2: Create New Repository
   → Click: + (top right) → New repository
   → Name: resume-builder
   → Choose: Public
   → Click: Create repository

STEP 3: Upload Files
   → Click: Add file → Upload files
   → Upload: index.html (the main file)
   → Click: Commit changes

STEP 4: Enable GitHub Pages
   → Go to: Settings tab
   → Click: Pages (left menu)
   → Source: main branch
   → Click: Save
   → Wait 2-3 minutes...

STEP 5: Your App is LIVE! 🎉
   → URL: https://[your-username].github.io/resume-builder
   
   Example: https://raj-bahadur.github.io/resume-builder

💡 HOW TO USE THE APP
═══════════════════════════════════════════════════════════════════════════════

1️⃣  CHOOSE TEMPLATE
   → Select from 3 designs: Modern, Professional, Creative
   → Click on your choice

2️⃣  FILL YOUR DETAILS
   → Personal Info: Name, Email, Phone, Location
   → Professional Summary: Brief overview (optional)
   → Experience: Add your job history
   → Education: Add degrees and institutions
   → Skills: List skills separated by commas

   → Right side shows live preview
   → See updates as you type

   → Click: "⬇️ Download PDF"

   → Use for job applications

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Page not loading
Solution: Clear cache (Ctrl+Shift+Delete) or try Incognito mode

Problem: PDF not downloading
Solution: Enable JavaScript or try Google Chrome

Problem: GitHub Pages not showing
Solution: Wait 5 minutes, check Settings → Pages is set to 'main'

Problem: Form looks weird on mobile
Solution: Rotate phone to landscape or use full-screen view
