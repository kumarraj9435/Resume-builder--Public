## **🚀 Quick Start - Deploy on GitHub Pages (Free)**

### **Step 1: Create GitHub Account**
- Go to https://github.com
- Sign up for free

### **Step 2: Create a New Repository**
1. Click `+` (top right) → `New repository`
2. Name it: `resume-builder` (or any name)
3. Description: `Professional Resume Builder App`
4. Choose `Public`
5. Click `Create repository`

### **Step 3: Upload Files**
1. In your repository, click `Add file` → `Upload files`
2. Upload the `index.html` file you received
3. Click `Commit changes`

### **Step 4: Enable GitHub Pages**
1. Go to `Settings` tab
2. Click `Pages` (left sidebar)
3. Under "Build and deployment":
   - Source: Select `Deploy from a branch`
   - Branch: Select `main` → `/ (root)`
4. Click `Save`

### **Step 5: Your App is Live!**
Your resume builder will be available at:
```
https://YOUR-USERNAME.github.io/resume-builder
```

Example: `https://raj-bahadur.github.io/resume-builder`

## **🆘 Troubleshooting**

### **PDF Download Not Working?**
- Make sure JavaScript is enabled in your browser
- Try a different browser (Chrome, Firefox, Edge)

### **Page Not Loading?**
- Clear browser cache (Ctrl+Shift+Delete)
- Try in Incognito mode

### **GitHub Pages Not Showing?**
- Wait 5-10 minutes after upload
- Refresh the page
- Check if branch is set to `main` in Settings → Pages
